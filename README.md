# Snakrrr

A minimal Python system info-fetcher that displays only essential information without bloat.

![Preview](https://github.com/user-attachments/assets/3eace1ee-6e55-459c-9ef9-0a0b0f7bcd01)

## Features

- cool snake!
- cant larp
- only useful info

## Installation

### Via PyPI
```bash
pip install snakrrr
```

### From Source
```bash
git clone https://github.com/Sharpnesse49/Snakrrr.git
cd Snakrrr
pip install -e .
```

## Usage

```bash
snakrrr
```
